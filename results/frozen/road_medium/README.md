# Road-medium evidence

Aggregate E/F/G results for the road-modulated Hodge operator, matched-media
tests and prior-plus-residual control. Full Null-1/Null-2 draw archives and
the largest raw JSON records remain in the analysis tree
`reports/roundE_graph_constitutive`, `reports/roundF_constitutive_evidence`
and `reports/roundG_directional_medium_null`; they are not bundled here.
The file names preserve the source experiment identifiers.
