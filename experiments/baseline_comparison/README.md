# Baseline comparison

`chengdu_nonlinear_exploratory.py` is the archived, explicitly exploratory
Chengdu full-FACE nonlinear comparison. It requires the external analysis
tree and is not part of the data-free reproduction path. The result is
underpowered with three TEST dates and supports neither the presence nor the
absence of nonlinearity.

The main model-comparison scores are frozen in
`results/frozen/crosscity/crosscity_results.csv`; Graph WaveNet per-date
errors are archived separately and are not retrained here.
