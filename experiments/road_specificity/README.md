# Road specificity

The rank-matched subspace test is an archived comparison of the road-induced
divergence-free basis with random conservation subspaces of the same rank. Its
frozen aggregate tables are in `results/frozen/matched_capacity/` and
`results/frozen/anisotropy/partA_topology.json`; the figure is generated by
`scripts/reproduce_figures/fig5_redesign.py`.

The original null construction depends on the external alignment and GIS
tree. No standalone public entry point is claimed. See
`configs/experiments/matched_capacity.yaml` and
`docs/known_limitations.md`.
